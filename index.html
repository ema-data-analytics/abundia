El sistema

Un sistema propio para Abundia

Las clientas reservan su turno online, a cualquier hora, y ustedes manejan todo el centro desde un mismo lugar: agenda, cobros, caja, profesionales, compras y gastos.

Turnos reales, sin superposicionesLa clienta ve solo los horarios libres. El sistema no permite dos turnos a la misma hora para la misma profesional o cabina.
Seña para asegurar el turnoSe confirma con una seña por transferencia. Si la clienta no viene, la seña queda para el centro.
WhatsApp mano a manoLos mensajes salen del WhatsApp del centro, armados por el sistema y enviados con un clic. Sin costos por mensaje.
Desde el celular o la PCFunciona en el navegador. Cada persona entra con su usuario y ve solo lo que le corresponde.
Datos de Abundia, protegidosBase de datos propia del centro, con copia de seguridad. Nada se borra: todo queda registrado con quién y cuándo lo hizo.
Simple de usarLas reglas del negocio se configuran una vez. En el día a día, cada acción es un clic.
Paso a paso

Cómo funciona un turno

  1. La clienta reserva onlineElige uno o varios servicios, la profesional (o "cualquiera disponible"), el día y el horario. Deja nombre, apellido y celular.
  2. Paga la señaEl horario queda guardado 30 minutos. Transfiere al alias del centro y sube el comprobante desde la misma pantalla. Si no lo sube a tiempo, el horario se libera solo.
  3. Recibe su constanciaCon número de turno, detalle de servicios, total, seña y saldo. Puede agregarlo a su calendario y volver a verlo con un link. Comprobante no válido como factura: es una constancia interna de control.
  4. Recepción confirmaControla la transferencia y aprueba la seña. El sistema arma el mensaje de confirmación y recepción lo envía por WhatsApp con un clic.
  5. Recordatorio el día anteriorLista de "Turnos de mañana" con el mensaje de recordatorio listo para enviar.
  6. La clienta llegaRecepción marca "Llegó". Si pasan 10 minutos de la hora sin llegar, el turno queda como ausente y la seña queda para el centro.
  7. Se cobra y terminaAl cobrar el saldo (efectivo, transferencia, tarjeta o QR) el turno queda terminado y alimenta la caja y las comisiones.

Cancelaciones: la clienta puede anular hasta 3 horas antes. La seña no se devuelve.

Base de datos

El sistema guarda toda la información de Abundia en una base de datos en la nube, separada de cualquier otro cliente.

Base de datos y alojamiento$ 50.000Por mes. Servicio Supabase (plan profesional), contratado en dólares.
  • Base de datos propia de Abundia: turnos, clientas, servicios, cobros, caja, compras y gastos.
  • Copia de seguridad diaria automática, para recuperar la información ante cualquier problema.
  • Archivos: comprobantes de seña que suben las clientas, fotos antes/después y consentimientos.
  • Usuarios con contraseña segura para dueñas, recepción y profesionales, cada una con sus permisos.
  • Funciona las 24 horas, para que las clientas reserven en cualquier momento.
  • La página de reservas y el sistema se publican sin costo adicional de alojamiento.
